# Capture provenance

Every image on the Quire page is either a screenshot of the real application or a page that Quire itself typeset, not a mock-up. All were made on 11 November 2026 on the maker's Windows 11 laptop from Quire 1.2.0 (release source `9369773`). The book shown is *Harrow Point*, a short sample EPUB whose text was written for this demonstration; it is not a real book and its text is free to reuse.

Window screenshots were rendered off-screen by Quire's own capture option at twice the normal pixel density (the option only changes the capture resolution, not the interface), then converted to WebP. The output folder shown in the window was set to a neutral example path. Nothing inside a window was drawn or retouched; the only edits are crops.
