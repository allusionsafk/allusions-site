Let the picture lead.

DemiMedia is a Windows film player built so the picture leads. You choose the result you want; it plans how to get there on your hardware, and it keeps the details one step away.

In development · no release yet · Follow it on GitHub

It starts quiet, too.

One question before anything else: what do you want to watch? A file, a folder or a stream. Everything else waits one step away.

Choose the result, not the settings.

Pick what you want from the picture: preserve the original look, improve detail, make motion smoother, clean up compression and banding, or a balanced improvement. Smart Fill can also reframe eligible video using source pixels only. Then say how strong, and whether to favour efficiency or quality.

There are four starting points: Automatic, Reference, Enhanced and Compatibility. The implementation parameters stay one level deeper.

See the plan before you press Play.

Before anything plays, DemiMedia reads the file and shows what it found and what it intends to do: the scaling it chose, whether motion is left alone, what audio path it will use, and why.

Nothing is marked as observed until the player has actually reported it.

While it plays, the detail stays one step away.

Healthy playback is quiet: no badges, no logs, no controls you did not ask for. Open Playback details and each question gets its own answer.

What it does, and what it does not claim

Plays through

mpv, libplacebo and FFmpeg; automatic MPC-BE fallback is unavailable in the current build

Hardware decoding on paths where it is supported

Decoded PCM as the safe audio default; HDMI bitstream optional

Offers, never silently

NVIDIA RTX Video Super Resolution and RTX Video HDR, where the hardware and active display path support them

Source-only Smart Fill for eligible video, with observed fallback to original framing when analysis is not trustworthy

Qualified native Dolby Vision Profile 7 processing and Profile 7 to Profile 8.1 conversion for compatibility, with delivery claims kept separate from requests

High-luminance wide-gamut SDR when Windows WCG is already active on a qualified built-in display, at the peak the display reports

Cinema Boost: an opt-in, temporary brightness raise on a qualified built-in display, on AC power only, restored afterwards unless you change it yourself

Does not claim

Universal Dolby Vision or HDR support on every display

Proprietary Dolby Vision display signalling unless the active path actually proves it

That wide-gamut SDR is HDR output, or that a brightness setting or renderer target is measured light output

AI frame generation or generated scenery; smoother motion currently blends real frames and Smart Fill only reframes source pixels

That a requested enhancement was delivered before the player reports it
